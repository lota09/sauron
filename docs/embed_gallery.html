사우론 · Discord 임베드 스타일 갤러리

discord.py 2.x discord.Embed 로 실제 구현 가능한 스타일 모음 · 다크테마 목업

Discord 임베드 구성요소: color(왼쪽 색막대) · author(작은 아이콘+이름) · title+url(파란 링크) · description · fields(name/value, inline) · thumbnail(우상단 소형) · image(하단 대형) · footer(아이콘+텍스트) · timestamp. 아래는 공지 알림용 A~F, 구독봇 UI용 G~K, 운영/디버그용 L 예시.
A 미니멀 공지 (가장 가벼움)

구현 메모 — 위 전부 discord.Embed(title=, url=, description=, color=) + .add_field(name=, value=, inline=True) + .set_author()/.set_thumbnail()/.set_footer()/.set_image() 조합으로 가능. 색상은 discord.Color 또는 0xFAA61A 정수. 컴포넌트(Select·Button)는 임베드와 같은 메시지에 붙음. 필드 inline은 3개까지 한 줄. 사우론 기본 추천: 공지=B(썸네일+필드)+C(색상코딩), 구독봇=G·H·I·J 흐름.

# 사우론의 눈 MCP — 테스터 안내

숭실대 학과·전교 공지(약 70개 게시판)를 **내 AI(Claude Code·Cursor·VS Code 등)에서 바로 물어볼 수 있게** 해 주는 MCP 서버입니다.
지금은 소수 테스터 대상 시험 운영입니다.

> **받은 것 두 가지**
> - 서버 주소: `<서버 주소>` (예: `https://…/mcp`)
> - API 키: `<API 키>` (`srn_`로 시작) — **개인 메시지로 따로 받습니다. 다른 사람에게 공유하지 마세요.**

---

## 1. 무엇을 할 수 있나

연결해 두면 AI가 필요할 때 스스로 공지를 찾아봅니다. 예를 들어:

- "컴퓨터학부 최근 공지 정리해 줘"
- "이번 주에 신청할 수 있는 장학금 있어?"
- "현장실습 모집 공지 찾아서 마감일 순으로 알려 줘"
- "AI대학이랑 학사공지에서 최근 2주 공지 중 3학년이 챙겨야 할 것만"

AI가 쓰는 도구는 두 개입니다: 공지 목록 조회·검색(`query_notice`), 공지 1건 상세(`get_notice`).
따로 명령어를 외울 필요는 없고, 평소처럼 물어보면 됩니다.

## 2. 연결하기

공통: **전송 방식 HTTP**, **주소** `<서버 주소>`, **헤더** `Authorization: Bearer <API 키>` 또는 `X-API-Key: <API 키>` (둘 중 아무거나).

### Claude Code (터미널) — 확인됨

```bash
claude mcp add --transport http sauron <서버 주소> --header "Authorization: Bearer <API 키>"
```

`claude mcp list`에서 `sauron … ✔ Connected`가 보이면 성공입니다. 이미 열려 있던 세션은 `/mcp`에서 다시 연결하거나 새로 시작하세요.

### Claude Code (VS Code 확장) — 확인됨

MCP servers → **Add MCP server**:

| 항목 | 값 |
|---|---|
| Name | `sauron` |
| Transport | HTTP (remote) |
| URL | `<서버 주소>` |
| Headers | `Authorization: Bearer <API 키>` |
| Scope | User (모든 프로젝트에서 사용) |

### Cursor — 미검증

`~/.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "sauron": {
      "url": "<서버 주소>",
      "headers": { "Authorization": "Bearer <API 키>" }
    }
  }
}
```

### VS Code (GitHub Copilot) — 미검증

`.vscode/mcp.json`(프로젝트) 또는 사용자 설정의 MCP 항목:

```json
{
  "servers": {
    "sauron": {
      "type": "http",
      "url": "<서버 주소>",
      "headers": { "Authorization": "Bearer <API 키>" }
    }
  }
}
```

### claude.ai 웹 — 확인됨

설정 → 커넥터 → **커스텀 커넥터 추가**:

| 항목 | 값 |
|---|---|
| 이름 · URL | `sauron-mcp` · `<서버 주소>` |
| 인증 | **로그인 없음** |
| 요청 헤더 | 이름 **`x-api-key`**, 값 `<API 키>` (`authorization`은 OAuth용이라 선택할 수 없음) |
| 전송 방식 | 스트리밍 HTTP (기본값) |

### ChatGPT 웹 — 미확인

> "미검증" 항목에서 연결이 되거나 안 되면 결과를 알려 주세요. 안내문에 반영합니다.

### 연결 확인

AI에게 이렇게 물어보세요: **"사우론 MCP로 최근 학사공지 3개 알려줘"**
제목·날짜가 나오면 정상입니다.

## 3. 알아 둘 점

**데이터**
- 10분마다 학교 사이트를 돌며 새 공지를 모읍니다. 그 이전 시점까지의 공지만 있습니다.
- 요약은 작은 AI 모델이 만든 것이라 **틀릴 수 있습니다.** 마감일·자격·제출서류처럼 중요한 내용은 AI에게 "원문 확인해 줘"라고 하거나 함께 오는 원문 링크를 직접 열어 보세요.
- 공지에는 **게시일·마감일 칸이 따로 없습니다.** 표시되는 시각은 사우론이 공지를 처음 발견한 시각입니다. 마감 여부는 AI가 본문을 읽고 판단합니다.
- 포스터 이미지에만 적힌 내용은 놓칠 수 있습니다.
- 서버가 수집을 멈춘 상태면 응답에 그 사실이 표시되고, AI가 "최근 공지가 빠졌을 수 있다"고 알려 줍니다.

**사용량 제한** — 한 사람이 1분에 30번(순간 15번)까지. 보통의 대화에서는 닿지 않습니다. 넘으면 잠시 후 다시 됩니다.

**개인정보** — 서버에는 접속 IP·호출한 도구·옵션·응답 크기·시각만 기록합니다. **질문 내용과 검색어는 기록하지 않습니다.** 기록은 14일 뒤 지워집니다.

**시험 운영** — 개인 장비에서 돌아가므로 예고 없이 멈추거나 주소·키가 바뀔 수 있습니다. 키는 테스터 공용이라, 유출되면 키를 바꾸고 다시 안내드립니다.

## 4. 피드백 부탁드리는 것

- AI가 원하는 공지를 **못 찾았거나 엉뚱한 공지를 가져온** 질문 (질문 문장 그대로 + 어떤 공지를 기대했는지)
- 요약이 원문과 다른 경우
- 연결이 안 되는 환경(클라이언트 이름·버전·오류 메시지)
- 있었으면 하는 기능
